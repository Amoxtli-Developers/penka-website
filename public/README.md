# Instrucciones para las imágenes

Este directorio contiene las carpetas para las imágenes que necesita el proyecto. Debes agregar las siguientes imágenes:

## Imágenes requeridas

1. **Hero Background**:
   - Nombre: `hero-bg.jpg`
   - Ubicación: `/public/hero-bg.jpg`
   - Recomendación: Imagen de alta calidad (1920x1080px) que muestre el ambiente del bar

2. **Bebidas (Menú)**:
   - Ubicación: `/public/drinks/`
   - Archivos requeridos:
     - `beer1.jpg`
     - `beer2.jpg`
     - `mezcal.jpg`
     - `cocktail1.jpg`
     - `michelada.jpg`
     - `coffee.jpg`
   - Recomendación: Imágenes cuadradas (600x600px)

3. **Eventos**:
   - Ubicación: `/public/events/`
   - Archivos requeridos:
     - `rock-rural.jpg`
     - `beer-fest.jpg`
     - `open-mic.jpg`
   - Recomendación: Imágenes con ratio 16:9 (800x450px)

4. **Galería**:
   - Ubicación: `/public/gallery/`
   - Archivos requeridos (del 1 al 9):
     - `gallery1.jpg`
     - `gallery2.jpg`
     - `gallery3.jpg`
     - ... hasta `gallery9.jpg`
   - Recomendación: Diversas dimensiones, pero mantener buena calidad

Si no dispones de estas imágenes, puedes usar placeholders temporalmente descargando imágenes gratuitas de sitios como Unsplash o Pexels.
