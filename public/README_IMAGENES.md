# Instrucciones para las imágenes

En este proyecto se han creado archivos de placeholder para todas las imágenes necesarias. Para un funcionamiento correcto del sitio, debes reemplazar estos placeholders con imágenes reales.

## Estructura de imágenes

1. **Imagen principal del Hero**
   - `/public/hero-bg.jpg` - Imagen de fondo para la sección Hero (preferiblemente 1920x1080px)

2. **Bebidas (Menú)**
   - `/public/drinks/beer1.jpg` - Imagen para "Penka Lager"
   - `/public/drinks/beer2.jpg` - Imagen para "El Harapo Stout"
   - `/public/drinks/mezcal.jpg` - Imagen para "Mezcal Campesino"
   - `/public/drinks/cocktail1.jpg` - Imagen para "Coctel Peña Colorada"
   - `/public/drinks/michelada.jpg` - Imagen para "Michelada del Haragan"
   - `/public/drinks/coffee.jpg` - Imagen para "Café de Olla"

3. **Eventos**
   - `/public/events/rock-rural.jpg` - Imagen para "Noche de Rock Rural"
   - `/public/events/beer-fest.jpg` - Imagen para "Festival de la Cerveza Artesanal"
   - `/public/events/open-mic.jpg` - Imagen para "Noche de Micrófono Abierto"

4. **Galería**
   - `/public/gallery/gallery1.jpg` - Imagen de galería 1 (preferiblemente una imagen destacada)

## Recomendaciones para las imágenes

- **Formato**: JPG o WebP para mejor rendimiento
- **Tamaño**: Optimiza las imágenes antes de subirlas (máximo 500KB para mejor rendimiento)
- **Dimensiones recomendadas**:
  - Hero: 1920x1080px
  - Bebidas: 600x600px (cuadradas)
  - Eventos: 800x450px (formato 16:9)
  - Galería: Dimensiones variables, pero manteniendo buena resolución

## Fuentes de imágenes gratuitas

Si no dispones de imágenes propias, puedes usar estos recursos:
- [Unsplash](https://unsplash.com) - Fotografías de alta calidad gratuitas
- [Pexels](https://pexels.com) - Fotografías y videos gratuitos
- [Pixabay](https://pixabay.com) - Imágenes y videos libres de derechos
